# Ponytail
Use before writing new utility functions or boilerplate code from scratch.
## Behavior
1. Search existing project libraries, dependencies, standard libraries, and browser APIs to check if the function already exists.
2. Reuse or extend existing utilities to reduce code duplication and maintain a lean codebase (target ~54% code reduction).
