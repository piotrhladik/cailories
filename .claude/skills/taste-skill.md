# Taste Skill
Use when designing web applications, UI components, landing pages, or when asked to eliminate generic AI aesthetics and establish a unique design system.
## Behavior
1. Establish a strong typographic hierarchy, custom color palette, and consistent spacing rules before writing UI code.
2. Avoid generic AI design tropes (pure black/white cards, overused purple gradients, generic sans-serif without styling).
3. Generate reference design specs or CSS variables.
