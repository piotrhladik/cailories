# Auto Research
Use when optimizing algorithms, prompts, hyper-parameters, or code performance through automated experiment loops (inspired by Andrej Karpathy).
## Behavior
1. Set up an isolated test harness.
2. Iteratively modify code/config, run benchmarks, measure metrics, and keep only the best-performing version.
