# GitHub CLI
Use for version control operations, creating repositories, managing branches, PRs, issues, and releases via `gh`.
## Behavior
1. Run `gh repo create`, `gh pr create`, `gh issue list`, etc., to automate GitHub workflows safely.
2. Commit changes frequently and push to remotes to prevent work loss.
