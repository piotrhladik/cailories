# NutriScan AI Development Plan

## Project Overview
NutriScan AI / FitCalorie AI — Hybrydowa aplikacja dietetyczna (Android + PWA).
Target: Google Play Store.

## Roadmap

### Phase 1: Foundations (Current)
- [ ] **System Pamięci**: Konfiguracja folderu `.remember` do logowania stanów sesji.
- [ ] **Offline-First Architecture**: Refaktoryzacja `storage.ts` i `useMealsStore.ts` (IndexedDB).
- [ ] **Play Store Readiness**: Konfiguracja `AndroidManifest.xml`, `build.gradle`, uprawnienia i wersje SDK.

### Phase 2: AI Brain Expansion
- [ ] **Gemini Vision**: Rozpoznawanie potraw ze zdjęć.
- [ ] **Fridge Mode + Recipe Gen**: Generowanie przepisów na podstawie składników w lodówce.
- [ ] **AI Nutrition Coach**: Personalizowany asystent z "osobowością".

### Phase 3: Monetization & Engagement
- [ ] **AdMob Full Integration**: Banery, Rewarded Ads, Interstitials.
- [ ] **Gamification**: Systemy nagród i streaków.
- [ ] **Analytics**: Integracja z systemami śledzenia retencji.

### Phase 4: Deployment
- [ ] **Assets & Legal**: Polityka prywatności, ikony, zrzuty ekranów.
- [ ] **Build Pipeline**: Automatyzacja budowania wersji produkcyjnej.

## Current Status
- Status: Planning / Phase 1 Start
- Last Action: Roadmap defined.
